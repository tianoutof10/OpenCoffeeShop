# Bestpresso v0.1.28 patch — Profile library controls

- **Delete created and imported profiles** from their detail page. A confirmation explains what will be removed; saved shots and their graphs remain intact.
- Deleted profiles are removed from your library and favorites using Decaid's recoverable deletion, not permanent purging. Built-in profiles remain protected. To delete the currently loaded profile, select another profile first.
- **Sleep is now the leftmost button** in the home-screen machine controls, followed by Cleaning and Settings, making standby easier to reach. Resolves [#52](https://github.com/xinghendri/bestpresso/issues/52).

Install the updated **bestpresso-v0.1.28.zip** in Decaid. The version remains 0.1.28; Brewing Insights and the existing brewing controls are retained.
